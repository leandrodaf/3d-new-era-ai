# Documentation

Start with the [project README](../README.md) for what 3D New Era AI does and how
to install it, and [CONTRIBUTING.md](../CONTRIBUTING.md) to build it and open a
pull request.

| Document | What it covers |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | The crates, the command model every change goes through, units, ids, MCP design, threads and security |
| [STANDARDS.md](STANDARDS.md) | The standards, design doctrine and research behind every ergonomics, lighting and joinery rule, and how much each source may accuse |
| [SHOWCASE.md](SHOWCASE.md) | A real 105 m² apartment built end to end by an AI agent through MCP |
| [ROADMAP.md](ROADMAP.md) | What is done, milestone by milestone, and what comes next |
| [DISTRIBUTION.md](DISTRIBUTION.md) | Where it runs (desktop, browser, hosted), every channel it is published on, the release flow and the hosted service |
| [CONNECTOR-REVIEW.md](CONNECTOR-REVIEW.md) | Descriptions, example prompts and test cases for the Claude and ChatGPT connector directories |

Other files here:

- [`images/`](images): screenshots and renders used by the README, the site and
  the documents above. `images/showcase/` is copied into the website at build
  time, so keep file names stable.
- [`projects/upper-west-side-reviewed.newera`](projects/upper-west-side-reviewed.newera):
  the browser demo apartment after an AI-assisted design review, with
  presentation views; [`upper-west-side-sheet.png`](projects/upper-west-side-sheet.png)
  is its presentation sheet. Open it in the desktop app or at
  [3dneweraai.com/app](https://3dneweraai.com/app/).

The changelog is at the repository root: [CHANGELOG.md](../CHANGELOG.md).
